# Kira Asal Masalah

A simple web calculator for Islamic inheritance (faraid) arithmetic.

## Live Site

Enjoy it here: [https://atifmustaffa.github.io/kalkulator-faraid](https://atifmustaffa.github.io/kalkulator-faraid)

## Features

- **Faktor Sepunya** — Find the common factor of two values using the greatest common divisor (GCD).
- **Asal Masalah** — Calculate the final base number using the least common multiple (LCM) and residue adjustment for asabah heirs.
- Local calculation history stored in your browser.
- Clean, responsive interface.
